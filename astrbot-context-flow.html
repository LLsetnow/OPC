Active in your instance

按轮截断

当前实例的快速保护策略。它不额外请求模型，因此在工具循环中很快，但会丢弃原始历史并改变提示词前缀。

  1. 保留开头的 system 消息。
  2. 删除最早的 1 轮非 system 消息。
  3. 修正 assistant tool call 与 tool result 配对。
  4. 仍超过阈值时，执行一次保留后半段的兜底截断。
Available alternative

LLM 摘要压缩

旧历史被归纳成一段可续接的摘要，最近内容保持原样。信息连续性更好，但会多一次模型调用，也同样会建立新的缓存前缀。

  1. 按 user 消息切分为完整对话轮。
  2. 当前实例默认可保留最近 15% 的 token 原文。
  3. 将更早历史交给压缩模型，生成续接摘要。
  4. 重建为 system + 摘要对 + 最近完整轮次。
